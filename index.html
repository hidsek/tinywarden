tinywarden を書き込む

ESP32-S3の基板に、tinywarden（USBで挿す、非公式のBitwarden互換サーバー）のファームウェア v0.3.0 を、ブラウザから書き込みます。

非公式・実験的なものです。Bitwarden, Inc. とは関係がなく、第三者の監査も受けていません。基板の中身は閉じていないので、基板を手にした人は暗号文を読み出せます（ユーザー名は基板に保存しないので、相手はユーザー名とマスターパスワードを組で当てる必要があります）。守りの中心は、マスターパスワードの長さと、でたらめに選んだユーザー名です。控えは必ず別の場所に持ってください。詳しくは GitHub のREADME。

書き込む

  1. パソコンの Chrome か Edge で、このページを開く（スマホやSafari、Firefoxは書き込みに使えません）
  2. 基板をUSBで挿し、書き込みモードにする: BOOTを押したまま、RSTを押して離し、BOOTを離す
  3. 下のボタンを押し、出てきた一覧から基板（「USB JTAG/serial debug unit」など）を選ぶ
  4. はじめて書き込むときは「Erase device（全部消す）」にチェックを入れる。すでに保管庫が入っている基板では、チェックを入れない（入れると保管庫も証明書も消えます）。v0.2から上げるときは例外で、先にエクスポートしてからチェックを入れて書き込み、インポートし直します（v0.3はv0.2の保管庫を開けません。MANUALの「v0.2からv0.3に移す」）
  5. 終わったら、基板のRSTを押して起動する
初回コード: （作成中）
このページを開くたびに新しく作り、ファームと一緒に書き込みます。アカウントを作るまで、基板の管理ページ（https://192.168.237.1/）をこのコードで開けます。書き込む前に控えてください（ページを開き直すと変わります）。アカウントを作ると、基板から消えます。基板に残るのはコードのハッシュだけです。

このブラウザは書き込みに使えません。パソコンのChromeかEdgeで開いてください。

このページはHTTPSで開く必要があります。

書き込むファイル: tinywarden-v0.3.0-esp32s3.bin（SHA-256 7d1dea28e32d6826f046f418d0c979284a2151c7c11e22d8357d1b1b9544c16b）。同じものがGitHubのReleasesにもあります。esptool.py --chip esp32s3 write_flash 0x0 <ファイル> でも書き込めます（そのときは初回コードは入りません。アカウントを作ってから、そのアカウントで管理ページを開きます。コードを入れるなら tools/setup_code.py と write_flash 0x3F0000）。

書き込んだあと

基板を挿すと、パソコンやスマホに新しい有線LANとして見えます（基板は 192.168.237.1）。証明書を信頼させてから、Bitwardenの拡張機能かアプリで、サーバーのURLを https://192.168.237.1 にします。機器ごとの手順は SETUP.md。

English

Flash tinywarden v0.3.0 (an unofficial, experimental Bitwarden-compatible server on an ESP32-S3 over USB) from Chrome or Edge on a computer. Put the board in download mode (hold BOOT, press and release RST, release BOOT), press the button above and pick the board. Tick "Erase device" only on a first install: it wipes any vault and certificate. Press RST when done. The page shows a one-time setup code and writes its hash to the board; until an account exists, it unlocks the board's status page, so note it before flashing. Coming from v0.2: export first, then flash with "Erase device" and import again (v0.3 cannot open a v0.2 vault). Not affiliated with Bitwarden, Inc.; not audited. See the README.
