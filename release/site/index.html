tinywarden を書き込む

ESP32-S3の基板に、tinywarden（USBで挿す、非公式のBitwarden互換サーバー）のファームウェア v{{VERSION}} を、ブラウザから書き込みます。

非公式・実験的なものです。Bitwarden, Inc. とは関係がなく、第三者の監査も受けていません。基板の中身は閉じていないので、基板を手にした人は暗号文を読み出せます。守りの中心はマスターパスワードの長さです。控えは必ず別の場所に持ってください。詳しくは GitHub のREADME。

書き込む

  1. パソコンの Chrome か Edge で、このページを開く（スマホやSafari、Firefoxは書き込みに使えません）
  2. 基板をUSBで挿し、書き込みモードにする: BOOTを押したまま、RSTを押して離し、BOOTを離す
  3. 下のボタンを押し、出てきた一覧から基板（「USB JTAG/serial debug unit」など）を選ぶ
  4. はじめて書き込むときは「Erase device（全部消す）」にチェックを入れる。すでに保管庫が入っている基板では、チェックを入れない（入れると保管庫も証明書も消えます）
  5. 終わったら、基板のRSTを押して起動する

このブラウザは書き込みに使えません。パソコンのChromeかEdgeで開いてください。

このページはHTTPSで開く必要があります。

書き込むファイル: tinywarden-v{{VERSION}}-esp32s3.bin（SHA-256 {{SHA256}}）。同じものがGitHubのReleasesにもあります。esptool.py --chip esp32s3 write_flash 0x0 <ファイル> でも書き込めます。

書き込んだあと

基板を挿すと、パソコンやスマホに新しい有線LANとして見えます（基板は 192.168.237.1）。証明書を信頼させてから、Bitwardenの拡張機能かアプリで、サーバーのURLを https://192.168.237.1 にします。機器ごとの手順は SETUP.md。

English

Flash tinywarden v{{VERSION}} (an unofficial, experimental Bitwarden-compatible server on an ESP32-S3 over USB) from Chrome or Edge on a computer. Put the board in download mode (hold BOOT, press and release RST, release BOOT), press the button above and pick the board. Tick "Erase device" only on a first install: it wipes any vault and certificate. Press RST when done. Not affiliated with Bitwarden, Inc.; not audited. See the README.
